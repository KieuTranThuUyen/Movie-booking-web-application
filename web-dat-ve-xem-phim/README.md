# Web đặt vé xem phim

## Giới thiệu

Website đặt vé xem phim trực tuyến, hỗ trợ khách hàng tìm kiếm phim, xem thông tin phim, lựa chọn suất chiếu, đặt vé, thanh toán và quản lý vé đã đặt.

Hệ thống gồm hai nhóm người dùng chính:

- **Khách hàng:** xem phim, tìm kiếm phim, xem suất chiếu, chọn ghế, đặt vé, thanh toán, xem vé, xem lịch sử đặt vé và hủy vé.
- **Admin:** quản lý phim, rạp chiếu, phòng chiếu, sơ đồ ghế, suất chiếu, người dùng, đơn đặt vé và theo dõi thống kê hệ thống.

Ngoài các chức năng đặt vé truyền thống, hệ thống có tích hợp:

- **AI Chatbot:** hỗ trợ khách hàng tìm phim, tìm suất chiếu và chuyển sang trang đặt vé.
- **AI Search:** tìm kiếm phim bằng ngôn ngữ tự nhiên.
- **AI Recommendation:** hỗ trợ đề xuất phim phù hợp.
- **Thanh toán SePay:** hỗ trợ quy trình thanh toán và cập nhật trạng thái thanh toán.
- **Mã QR:** tạo mã QR cho vé và Combo sau khi đặt vé thành công.
- **Hủy vé:** hỗ trợ hủy từng vé/Combo hoặc hủy toàn bộ các mục đủ điều kiện.
